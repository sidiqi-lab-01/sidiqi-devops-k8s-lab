# Sidiqi DevOps Kubernetes Lab

Enterprise-style DevOps lab built on AWS.

## Goals

- AWS infrastructure
- Terraform Infrastructure as Code
- Ansible configuration management
- Docker containerization
- RKE2 Kubernetes
- Helm
- ArgoCD
- Jenkins CI/CD
- Git/GitHub
- Microservices
- Linux and Bash automation
- Networking
- Storage
- DevSecOps
- Monitoring
- Air-gapped deployment simulation
- AI-assisted engineering

## Architecture

AWS → VPC → EC2 → RKE2 → Kubernetes → Microservices
